────────────────────────────────────────

  3. Choose strategy
  4. Process all files at once!

QUICK EXAMPLES
================================================================================

GUI Application:
  C:\optimizer> run.bat
  → Graphical interface opens
  → Drag MIDI files, choose strategy, optimize

Single File:
  C:\optimizer> optimize.bat C:\Music\song.mid
  → Creates: song_optimized.mid in same folder

With Output Path:
  C:\optimizer> optimize.bat C:\Music\song.mid C:\Output\song.mid EXPRESSIVE
  → Creates: C:\Output\song.mid with EXPRESSIVE strategy

Analyze First:
  C:\optimizer> analyze.bat C:\Music\song.mid
  → Shows velocity distribution, programs used, etc.

Batch Process:
  C:\optimizer> batch_process.bat C:\Music\MIDI C:\Optimized AUTHENTIC
  → Processes all .mid files in C:\Music\MIDI
  → Outputs to C:\Optimized

================================================================================
TROUBLESHOOTING
================================================================================

"Python not found"
  → Install Python from python.org
  → Make sure to check "Add Python to PATH"

"ai_database.json not found"
  → Ensure file is in same folder as batch files
  → Download file if missing

GUI won't open
  → Try command line: python midi_optimizer_gui.py
  → Use optimize.bat instead

Nothing seems to work
  → Run: install.bat (again, it will diagnose issues)
  → Read: WINDOWS_BATCH_README.md

WORKFLOW EXAMPLES

  3. Load both into DAW
  4. Compare and choose
  Done! You now know which strategy works best!
