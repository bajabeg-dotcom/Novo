What this tool does right now

This is a preview build. It can import and analyze a Standard MIDI File — parse its structure, validate it, and show raw per-track facts (channel, notes, velocity, Program Change, CC, SysEx) — using the same code that already processes the real KORG PA800 Factory Style corpus.

It does not optimize MIDI yet. The GM→RX mapping, Instrument Identity, RX Safety Engine, Gold DNA, and Optimizer are not implemented (see docs/ROADMAP.md, Phase 5 onward) — so there is no "Optimize" button here. Building that fake would violate this project's own no-black-box, evidence-based rule.
