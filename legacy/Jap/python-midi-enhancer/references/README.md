# Korg Pa800 — normativni izvori

Službeni priručnici učitani su u projekt kao:

`prism-uploads/Pa800-201UM-ENG.pdf`

`prism-uploads/Pa800_AE_E.pdf`

Prvi dokument je **KORG Pa800 2.0 User's Manual (E12)**, a drugi **KORG Pa800
2.0 Advanced Edit Manual (E5)**. Njihovi kontrolni zbrojevi i broj stranica
zapisani su u `main.tex`.

Službena Korg stranica User's Manuala:

`https://www.korg.com/us/support/download/manual/1/193/2268/`

Za svaki Pa800 modul obavezno se bilježe:

- SHA-256 kontrolni zbroj;
- broj stranica;
- naslov i verzija iz samog PDF-a;
- stranice korištene za svaki modul.

Forumi, videozapisi, drugi modeli i pretpostavke ne smiju se koristiti kao
normativni dokaz. Mogu služiti samo za otkrivanje pitanja koja zatim moraju biti
potvrđena u službenim Pa800 dokumentima.
