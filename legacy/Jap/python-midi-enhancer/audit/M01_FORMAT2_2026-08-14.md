# M01/M02 SMF Format 2 audit — 2026-08-14

## Decision

**PASS** for the explicitly bounded, read-only SMF Format 2 scope.

This does not certify the entire SMF standard, cross-parser event parity,
SMPTE musical-time analysis, writer behavior or Enhance.

## Problem found

Both built-in parsers accepted header format value 2, but the main analyzer
previously combined tempo events from independent Format 2 sequences into one
false global timeline. The 16-slot display and GUI also described Format 2 as
Format 1 physical tracks. A test that merely asserted successful parsing would
have certified incorrect behavior.

## Implemented behavior

- Each Format 2 physical track is represented as an independent `Sequence`.
- Tempo, end tick and duration are calculated separately for each sequence.
- The global result is `PARTIAL` with timeline semantics
  `INDEPENDENT_SEQUENCES`.
- Global `duration_ticks`, `duration_seconds`, `initial_bpm` and
  `tempo_changes` are `null` instead of guessed or merged.
- Aggregate note statistics remain available but do not imply a shared musical
  timeline.
- The 16-slot display labels Format 2 sources as `Sequence 1`, `Sequence 2`,
  and so on.
- GUI summary wording is `PER SEQUENCE` and `PARTIAL / READ-ONLY`.
- Global `pretty_midi` tempo/beat analysis and `music21` harmonic analysis are
  explicitly skipped for Format 2 even if those optional libraries are
  available.
- `mido`, when available, may still be used only for structural validation.
- The original file and SHA-256 remain unchanged.

## Dedicated tests

File: `tests/test_midi_format2.py`

The four tests verify:

1. two sequences with different tempos do not create a global duration or
   tempo;
2. display slots keep sequences separate and the human report explains the
   missing global duration;
3. global optional analyzers are not imported for Format 2;
4. `MidiAnalyzer` and `StandardMidiLoader` agree on format, track count,
   division, source hash and per-track end ticks, while the byte-preserving
   parser reconstructs each original track body exactly.

Dedicated/regression command:

```bash
python -m pytest -q tests/test_midi_format2.py tests/test_midi_modules.py
```
